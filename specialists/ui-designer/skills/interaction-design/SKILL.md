# Interaction design

## Scope

- Navigation models, modals vs. pages, destructive action patterns
- Form behavior: validation timing, inline vs. summary errors
- Selection, bulk actions, drag-drop (if applicable)
- Keyboard and pointer paths (coordinate with Accessibility)

## Deliverables

- Flow diagrams (Figma FigJam or page in file)
- Interaction table in `templates/ui-spec-sheet.md`
- Annotations on frames: trigger, guardrails, edge cases

## Principles

- Match platform conventions unless research supports a deliberate break
- Prefer **recognition over recall**; expose system status
- Destructive actions require confirmation or undo when possible

## Handoff

Chief uses interaction table to align copy, motion, and a11y in reconciliation.
