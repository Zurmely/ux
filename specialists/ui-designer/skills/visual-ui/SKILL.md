# Visual UI

## Process

1. Establish page templates (grid, spacing scale from design system).
2. Apply type hierarchy and color tokens; avoid raw hex except in token definitions.
3. Design key screens first; derive secondary screens from patterns.
4. Document spacing and alignment in component instances where non-obvious.

## Pairing

- **UX Writer** — length and hierarchy
- **Illustrator** — asset slots and aspect ratios
- **Design systems** — token and component sourcing

## Done when

Screens match brand, use system components, and spec sheet lists all frames.
