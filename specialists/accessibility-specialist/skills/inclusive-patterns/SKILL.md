# Inclusive patterns

## When to use

- Greenfield flows
- New components in design-systems work
- Repeated audit themes across projects

## Deliverable

Short pattern doc: when to use, anatomy, a11y requirements, anti-patterns.

Examples:

- Accessible form validation (inline, programmatic association)
- Skip links and landmarks
- Live regions for toasts
- Accessible data tables and charts (high-level)

## Handoff

Link patterns in audit report or UI spec; Chief adds to decision log if pattern overrides UI default.
