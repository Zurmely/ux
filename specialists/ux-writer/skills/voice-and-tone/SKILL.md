# Voice and tone

## When to use

- No voice guidelines exist
- Copy feels off-brand across flows
- Chief asks for a **voice snapshot** before wide UI copy

## Process

1. Gather brand materials (marketing site, CEO narrative, existing UI).
2. Draft **voice attributes** (3–4 adjectives) with do/don’t examples.
3. Define **tone sliders** by context (celebratory vs. serious, formal vs. casual).
4. Provide **before/after** examples for key patterns (errors, empty states, CTAs).

## Output

Section in copy deck or standalone Drive doc linked from handoff packet.

## Quality

Examples must be **specific to the product**, not generic “friendly and professional.”
