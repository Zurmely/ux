# Micro-interactions

## Focus areas

- Hover / press / focus feedback (coordinate with UI visual states)
- Success / error confirmation
- Skeleton and loading shimmer (avoid seizure triggers; respect reduced-motion)

## Deliverable

Add rows to motion spec; optional short Lottie/video reference in Figma if brand allows.

## Pairing

Work with **UI Designer** (`interaction-design` sub-skill) on trigger definitions.
