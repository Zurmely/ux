# Motion spec

## Steps

1. Inventory screens with motion from Chief brief.
2. Define **global tokens** (durations, easings) for consistency.
3. For each animation: trigger, affected layers, properties, timing, interruptibility.
4. Document **reduced-motion** behavior per row.
5. Cross-reference Figma frame names in the spec table.

## Reference

Use `templates/motion-spec.md`. Prefer ms and explicit easing curves.
