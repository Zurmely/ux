# Iconography

## Process

1. Audit existing icons (Figma library or app).
2. Define grid, stroke, corner, and optical alignment rules.
3. Design icons in sets; map to semantic names for eng (`icon-add`, not `icon-plus-blue`).
4. Pair with Accessibility: decorative vs. informative icons flagged for labels.

## Output

Figma icon components + row in export checklist.
