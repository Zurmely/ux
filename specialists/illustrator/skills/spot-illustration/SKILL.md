# Spot illustration

## Process

1. Confirm metaphor with Research/Chief (avoid culturally narrow symbols).
2. Sketch composition within UI safe zone from UI Designer.
3. Finalize in brand palette; provide dark-mode variant if needed.
4. Supply alt text draft for UX Writer polish.

## Output

Figma frames + export checklist entries.
