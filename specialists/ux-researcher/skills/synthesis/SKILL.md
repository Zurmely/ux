# Synthesis

## Process

1. Affinity-map observations (FigJam or spreadsheet).
2. Cluster themes; name with user-centered labels.
3. Separate **finding** from **recommendation**.
4. Mark confidence; flag thin evidence.
5. Produce insight summary with P0/P1 recommendations.

## Output

`templates/insight-summary.md` — Chief uses this in reconciliation and decision log.
