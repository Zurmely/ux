# Usability testing

## Process

1. Task scenarios tied to research questions (realistic, not leading).
2. Prototype from UI Designer or staging build.
3. Moderate or unmoderated per plan; record if permitted.
4. Debrief within 24h; tag issues by severity.

## Severity rubric

- **Critical:** blocks core task
- **Major:** workaround exists, significant friction
- **Minor:** polish

Feed severities into insight summary for Chief prioritization.
